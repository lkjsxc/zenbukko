# Decisions

## Purpose

Record accepted behavior decisions that affect multiple docs areas.

## Files

- [`ocr-defaults.md`](ocr-defaults.md): OCR backend and mode defaults.
- [`web-security.md`](web-security.md): local web binding and token behavior.
- [`container-split.md`](container-split.md): Web proxy and Core API container split.
- [`whisper-backends.md`](whisper-backends.md): strict CPU, CUDA, and Vulkan runtime resolution.

## Invariants

- Decisions describe locked behavior, not proposed alternatives.
- Feature and reference docs must agree with these pages.
