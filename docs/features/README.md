# Features

## Purpose

User-visible behavior contracts for Zenbukko features.

## Files

- [`sessions/`](sessions/README.md): session import and storage.
- [`chapter-selection/`](chapter-selection/README.md): range parsing and ID mapping.
- [`confirmation-tests/`](confirmation-tests/README.md): read-only confirmation-test capture.
- [`materials/`](materials/README.md): material download and PDF normalization behavior.
- [`ocr/`](ocr/README.md): local OCR behavior.
- [`transcription/`](transcription/README.md): whisper.cpp behavior.
- [`report-prompts/`](report-prompts/README.md): prompt generation from OCR and transcripts.
